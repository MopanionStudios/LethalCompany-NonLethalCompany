# **Non-Lethal Company**

## **Work for The Company with the whole family!**

**This mod disables all blood effects and dismemberment.**

Queasy at the sight of blood? Want to play but you or a loved one doesn't appreciate the violence? Simply want a cleaner experience? Look no further!

This mod aims to remove all sources of blood, gore, and dismemberment from the game.

This mod hasn't been updated in a few years, and I have a friend who needs it, so I had Claude fix it up for V85 because I haven't used C# in over a year and have never made an actual plugin for a game myself.

Here is the repo for the original, all credit goes to the author: https://github.com/Gweneg/LethalCompany-NonLethalCompany
